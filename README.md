# 📒 دفتري

تطبيق ويب بسيط (ملف واحد `index.html`) يعمل بدون إنترنت، فيه:

- **جهات الاتصال**: أرقام العائلة والأصدقاء والزملاء، مع البحث والتصفية والاتصال المباشر وواتساب وتاريخ الميلاد.
- **الفواتير**: المبلغ وتاريخ الاستحقاق والتكرار (شهري/سنوي) وحالة الدفع وسجل الدفعات.
- **المواعيد والتواريخ المهمة**: التاريخ (ميلادي مع الهجري) والوقت والمكان والتكرار السنوي.
- **استيراد الأرقام دفعة واحدة**: من ملف vCard (.vcf) أو CSV مصدَّر من الجوال أو Google، أو اختيار مباشر على أندرويد. المكرر يُتجاهل.
- **المصروفات**: لصق رسائل البنك (تُقرأ المبالغ والمتجر والتاريخ والتصنيف تلقائياً)، استيراد كشف حساب CSV، وتسجيل تلقائي عبر رابط `#sms=` من اختصارات آيفون أو MacroDroid.
- **الرئيسية**: ملخص وكل ما هو قادم خلال 30 يوماً (مواعيد، فواتير، أعياد ميلاد).
- **نسخ احتياطي**: تصدير واستيراد البيانات كملف JSON.

## التشغيل
افتح `index.html` في أي متصفح. البيانات تُحفظ على الجهاز نفسه داخل المتصفح، فصدّر نسخة احتياطية بانتظام.
