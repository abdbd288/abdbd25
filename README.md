# 📒 دفتري

تطبيق للجوال والكمبيوتر يتثبّت من المتصفح (PWA) ويشتغل بدون إنترنت. فيه:

- **جهات الاتصال**: العائلة والأصدقاء والزملاء، مع الاتصال المباشر وواتساب وأعياد الميلاد. تقدر تستورد كل أرقام جوالك مرة وحدة من ملف vCard أو CSV، أو تختارها مباشرة على أندرويد.
- **الفواتير**: المبلغ وتاريخ الاستحقاق والتكرار، وسجل الدفعات.
- **المواعيد والتواريخ المهمة**: بالميلادي والهجري، مع التكرار السنوي.
- **المصروفات**: تلصق رسائل البنك أو تستورد كشف حساب CSV، ويطلع منها المبلغ والمتجر والتصنيف لحاله. وفيه تسجيل تلقائي عبر رابط `#sms=` من اختصارات الآيفون أو MacroDroid.
- **قفل التطبيق**: رمز من 4 إلى 6 أرقام، مع البصمة أو Face ID، وقفل تلقائي، وإيقاف مؤقت بعد المحاولات الخاطئة.
- **نسخ احتياطي**: تصدير واستيراد.

**الخصوصية:** البيانات تنحفظ على جهاز كل مستخدم وبس، وما ترسل لأي خادم.

## النشر (عشان تشاركه برابط)
التطبيق ملفات ثابتة: `index.html` و`manifest.webmanifest` و`sw.js` ومجلد `icons/`. ارفعها على أي استضافة HTTPS:

- **GitHub Pages:** من إعدادات المستودع افتح Settings ثم Pages، واختر Deploy from a branch، وبعدها اختر الفرع والمجلد `/ (root)`. الرابط يصير `https://<user>.github.io/<repo>/`.
- **Netlify Drop:** اسحب المجلد كامل إلى app.netlify.com/drop.

بعدها أرسل الرابط لأي شخص. يفتحه ويضغط «📲 تثبيت»، أو في الآيفون: زر المشاركة ثم «إضافة إلى الشاشة الرئيسية».

عند أي تحديث للملفات غيّر `VERSION` في `sw.js`، عشان توصل النسخة الجديدة للأجهزة اللي ثبّتت التطبيق.

## تطبيق أندرويد (APK)
الملف الجاهز: `dist/Daftari.apk`. ترسله لأي أحد، يضغط عليه ويثبّته.

نفس التطبيق، ويضاف له:
- جلب **كل الأرقام من جهات الاتصال** دفعة واحدة.
- قراءة **رسائل البنك** من الجوال. بعد أول مراجعة، يسجّل العمليات الجديدة لحاله من نفس البنوك كل ما ينفتح.
- الفتح بالبصمة أو قفل الجوال.
- مشاركة التطبيق نفسه (ملف APK) عبر واتساب.

البناء (Ubuntu):
```bash
apt-get install android-sdk-platform-23 aapt apksigner zipalign dalvik-exchange
KEYSTORE=/path/daftari.keystore KS_PASS=... android/build.sh
```
**مهم:** وقّع كل تحديث بنفس المفتاح (`daftari.keystore`). إذا تغيّر المفتاح، لازم يحذف المستخدم التطبيق قبل التحديث، وتنحذف بياناته.
عند كل تحديث زِد `versionCode` في `android/AndroidManifest.xml`.
